# Code of Conduct

AGSignal project spaces should stay professional, technical, and safe for
contributors.

## Expected Behavior

- Be respectful and direct.
- Critique code, designs, and claims rather than people.
- Assume public discussion can be read by future users and contributors.
- Keep security-sensitive details in private reporting channels.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing another person's private information.
- Sharing secrets, exploit details, or vulnerability reports in public issues.
- Repeated disruption of project discussions after moderator direction.

## Enforcement

Maintainers may edit, hide, or remove comments; lock discussions; restrict
participation; or block users when needed to protect the project community.
Report conduct concerns privately to the repository maintainers.
