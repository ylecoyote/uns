- Global engine configuration via `configure_ack_engine()` and `get_ack_engine()`

### 2. API Routes (`src/mcp_server/routes_notification.py`)
Per PRD Task 10 requirements:

**Endpoints:**
- `POST /v1/notifications/{id}/ack` - Acknowledge a notification
  - Request body: `{acked_by?: string, metadata?: object}`
  - Returns 200 with ack details on success
  - Returns 404 if notification not found
  - Returns 409 if invalid status transition

- `POST /v1/notifications/{id}/dismiss` - Dismiss a notification
  - Request body: `{dismissed_by?: string, metadata?: object}`
  - Same response codes as ack endpoint

- `GET /v1/notifications/{id}` - Get notification status
  - Returns full notification details + ack status
  - Returns `found: false` if notification not in storage

- `GET /v1/notifications/{id}/ack-status` - Get ack status only
  - Returns just the ack status or null if not tracked

**Features:**
- Pydantic request/response models with validation
- Proper HTTP status codes (200, 404, 409)
- Structured error responses
- Logging for audit trail
- Auto-initialization of ack engine
